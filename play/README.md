# play/ — reconstruction v0

Open `index.html` in a browser (double-click or `python3 -m http.server` from repo root and visit `/play/`).

Authentic 2-bit patterns from MSGORPAT (`GORF-PAT`, `PLY1-P`) with a modern game loop and write-overlay collision.

This is intentionally **not** `XC.LOGIC`; it proves the art and collision idea before a faithful CPU harness.
